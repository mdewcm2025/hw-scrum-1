list

列出 wcm2025 學員的作業網站與倉儲

上列程式是利用 Brython 讀取 https://mde.tw/list/1a.txt 資料後, 根據各學員的作業網站與倉儲連結建立 html.

若 github 尚未出現在 https://github.com/mdecycu/list 倉儲中, 或之後改變 github 帳號, 可以利用 Pull Requests 要求加入或變更.

Pull Requests (拉回請求, 或可稱為請求拉回合併) 使用時機:

當 Github 帳號無法直接對某一個倉儲進行改版, 但卻希望更動該倉儲的內容時, 可以透過 Pull Requests 流程要求對倉儲內容改版 (此流程稱為"正向拉回請求")

所謂"正向拉回請求", 是先登入 Github 帳號後, Fork 希望對其改版的倉儲後, 由於該倉儲已經被 Fork 進自己的帳號下, 因此對該 forked 倉儲擁有更改的權限.

forked 倉儲更改後, 可以建立拉回請求, 要求擁有對該倉儲管理權限的用戶透過內容檢視, 自行決定是否將改版內容進行合併.

至於"逆向拉回請求"則是 forked 倉儲希望從所 Fork 的倉儲擷取內容時, 只要將"正向拉回請求"的雙方帳號對調, 就可以建立本身有權限合併的 Pull Requests.
